# Архитектура

1. **Получение кандидатов.** Три TF-IDF канала: символьные n-граммы заголовка, словные n-граммы заголовка и словные n-граммы описания. Четвёртый канал — базовая `intfloat/multilingual-e5-base` в локальном INT8 ONNX-инференсе (Модель не дообучалась, из-за ограничения в ресурсах (нет дискретной gpu с cuda)).
2. **География.** Поиск ведётся глобально и внутри точной либо восстановленной по train локации объявлений.
3. **Реранжирование.** `HistGradientBoostingClassifier` выбирает 50 объявлений из объединённого пула. Он использует ранги каналов, cosine similarity E5, географическую историю, пересечение слов заголовка и запроса, рейтинг, цену, признаки связи и совпадения параметров запроса с параметрами объявления.

Для E5 используются префиксы `query:` и `passage:`. Документ состоит из заголовка (до 40 токенов) и параметров объявления (до 56 токенов); описание обрабатывается отдельным TF-IDF каналом. 

# Проверка качества

Строки train группируются по полному набору полей `search_*`, чтобы одинаковые запросы не попадали одновременно в обучение и проверку. Итоговый скор составил на локальных тестах Recall@50 **0,781821** и **0,786416** на двух независимых срезах по 2 452 query-группы.

# Запуск
В процессе я кешировал эмбединги e5, вы можете запустить их создание для генерации answer.csv сами или скачать с диска https://drive.google.com/file/d/1bsb2_gepbCwmuJsVJIxdqXTam5PSNukh/view?usp=sharing
```bash
python -m pip install -r requirements.txt
python dense_retrieval.py --download  # скачать модель e5
python -u solution.py
```
